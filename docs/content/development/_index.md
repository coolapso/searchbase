This section is for people working on the Searchbase source code. Start with
[Contributing](/development/contributing/) to build and run the checkout or
open a pull request. Use [Load testing](/development/load-testing/) for the
isolated benchmark stack.

If you want to run Searchbase as a service, start with
[Getting Started](/docs/getting-started/) and [Self Hosting](/docs/self-hosting/).
The deployable demonstration files live under `examples/compose/` and
`examples/k8s/`; checkout-built stacks live under `dev/compose/`.
